# Crafteris Studio

Crafteris Studio is a custom website and admin management system for a creative pottery and glass studio in Malta.

The project contains:

- the public Crafteris website
- an admin dashboard
- workshop management
- programme/course management
- memberships
- products
- gift vouchers
- contact enquiries
- website content editing
- image/media management
- studio settings
- Supabase database
- Supabase authentication
- Supabase storage
- cookie consent
- legal pages

This README explains how to install, run, manage and deploy the project even if you have never worked with a web project before.

---

# 1. What You Need

The project uses:

- GitHub — stores the website code
- VS Code — used to open and edit the project
- Node.js — required to run the website
- Supabase — database, login system and image storage
- Netlify — hosts the live website

The basic structure is:

GitHub
   ↓
Website code
   ↓
Netlify
   ↓
Live website

Website content
